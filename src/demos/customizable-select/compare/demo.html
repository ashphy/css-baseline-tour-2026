STEP 1

これまでは中身を変えられない

select は、枠や文字色は変えられても、開いたときの一覧はブラウザ任せでした。選択肢に書けるのも文字だけです。

下の select を開いてみてください。

STEP 2

appearance: base-select で自由に作る

select と ::picker(select) に appearance: base-select を指定すると、一覧も含めて CSS で見た目を変えられます。選択肢には画像や説明文などの要素も書けます。

未対応のブラウザでは

button や selectedcontent は無視され、STEP 1 と同じ従来の select になります。選択肢は文字だけが表示されます。
